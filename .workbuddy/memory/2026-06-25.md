## 部署前后端到服务器（两次）

- 服务器：106.52.246.40, ubuntu, Ubuntu 24.04 LTS
- 前端路径：/var/www/a2ui/（nginx 托管，端口 80）
- 后端路径：/home/ubuntu/a2ui-server/（PM2 进程 a2ui-server，端口 3847）

### 遇到的问题
- a2ui-react tsc 构建失败（Cannot find module 'a2ui-core'），前端改用 vite build 直接构建跳过 tsc
- server tsc 增量编译导致 mockStream.js 不生成，需删除 dist/ 和 .tsbuildinfo 后强制重编
- /var/www/a2ui/ 权限属 www-data，需通过 /tmp 中转上传

### Nginx 配置
- /etc/nginx/sites-available/a2ui（合并了 a2ui-frontend.conf）
- location / → 前端静态页
- location /api/ → 后端 3847
- location ^~ /admin → yadan-report 3456
- location ^~ /api → yadan-report 3456（考勤监控 API）

### 部署流程
1. vite build 前端 → scp index.html + assets 到 /tmp → sudo cp 到 /var/www/a2ui/
2. rm -rf dist + .tsbuildinfo → npx tsc 后端 → scp dist/ 到 /home/ubuntu/a2ui-server/dist_new → mv → pm2 restart

### Bug 修复 (17:22)
- 后端启动报错 `ENOENT: /home/docs/server_to_client_with_standard_catalog.json`
- 原因：`protocolBundle.ts` 用 `__dirname` 相对路径 `../../../../docs` 定位协议文件，服务器上缺少 `/home/docs/` 目录
- 修复：在服务器创建 `/home/docs/`，上传 `server_to_client_with_standard_catalog.json` 和 `catalog_definition.json`
- 同时发现 mock 文件缺失 `/home/packages/a2ui-core/mock/*.json`（mock 模式用，LLM 模式不受影响）
